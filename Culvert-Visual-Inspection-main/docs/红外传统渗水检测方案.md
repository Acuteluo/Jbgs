# 红外传统渗水检测技术方案

**版本：** v1.0  
**适用对象：** 涵洞 / 隧道壁面巡检机器人  
**实现路径：** 标准 UVC 红外灰度流 + OpenCV，无厂家 SDK、无深度学习标注

---

## 1. 方案定位

本方案面向巡检机器人搭载的 **UVC 红外模组**（白热 White-Hot 伪彩/灰度输出），在 **不接厂家测温 SDK、不训练神经网络** 的前提下，仅处理标准 8 位单通道灰度流，实时给出壁面渗水区域。

| 项目 | 约定 |
| --- | --- |
| 输入 | V4L2 / UVC，单通道 `CV_8UC1`（三通道伪彩先转灰度） |
| 输出 | 渗水连通域 BBox、像素掩膜 Mask、面积（像素 / 可选物理面积） |
| 依赖 | OpenCV 4.x，无第三方热像 SDK |
| 算力 | 工控机 CPU 即可；典型 256×192 / 640×480 可达实时 |
| 不依赖 | 绝对温度标定、全局灰度阈值、样本标注 |

与深度学习方案的分工：本算法作为 **可解释、可现场调参的基线检测器**，适合通风涵洞、温差稳定、水斑尺度小于视野的工况；大面积漫湿、黑热模式、强反射金属面需按第 8 节规避或升级。

---

## 2. 核心逻辑与物理依据

### 2.1 白热模式下的水体热特征

标准 **白热（White-Hot）** 映射约定：辐射温度越高，灰度越亮。

涵洞壁面渗水在红外图上表现为 **局部偏暗的灰度凹陷**，原因通常叠加：

1. **蒸发吸热**：水膜表面蒸发带走潜热，湿区温度低于紧邻干燥混凝土。
2. **地下水/渗流水天然低温**：来自岩体或管网的水体本身低于壁面环境温度。
3. **比热与热惯性**：湿区升温更慢，在巡检灯光/气流扰动下仍保持相对冷斑。

因此，渗水 **不是** “全图最暗的点”，而是相对 **紧邻干燥背景** 更暗的斑块。

### 2.2 为何不用全局绝对灰度阈值

UVC 红外模组普遍开启 **AGC（自动增益控制）**：

- 环境整体变暖/变冷、镜头进洞后平均辐射变化，全图会被整体拉亮或压暗；
- 同一块水渍在不同时刻的绝对灰度可能从 80 漂到 140；
- 固定阈值 `gray < T` 会随 AGC 周期性误检或漏检。

本方案改用 **局部差分**：

\[
\Delta(x,y) = B(x,y) - I(x,y)
\]

其中 \(I\) 为当前帧灰度，\(B\) 为由超大核平滑得到的 **理论干燥背景场**。  
渗水处 \(I < B\)，故 \(\Delta\) 为正且显著；AGC 造成的全局平移在 \(B\) 与 \(I\) 中同时出现，相减后被抵消。

判定依据是 **当前点与紧邻干燥背景的灰阶差**，而不是全图像素的绝对黑白。

## 3. 算法处理管线

整体数据流：

```
UVC/V4L2 帧
    → 单通道 8U 灰度
    → [可选 CLAHE]
    → CV_32F 提升
    → 超大核高斯 → 背景场 B
    → Diff = B − I
    → 阈值二值化
    → 形态学开运算
    → 连通域 / 轮廓
    → BBox + Mask + 面积
```

### 3.1 数据接入与类型提升

- 以 `cv::VideoCapture(index, cv::CAP_V4L2)` 打开模组，不调用厂家 SDK。
- 若相机输出 BGR 伪彩，先 `cvtColor(..., COLOR_BGR2GRAY)`，得到 `CV_8UC1`。
- **必须** `convertTo(CV_32F)` 后再做减法。  
  8 位无符号减法在 OpenCV / numpy 中都会 **下溢截断**：`80 - 100 → 0`，负差被抹成 0，冷斑信息丢失。浮点减法才能保留 \(\Delta\) 的符号与幅度。

### 3.2 基准背景场构建

对浮点图做超大核高斯滤波：

\[
B = G_{\sigma} * I,\quad \text{ksize} \in \{51, 61, \ldots, 101\}
\]

物理含义：核尺度远大于单块水渍直径时，滤波把局部冷斑 **抹进周围干燥壁面的灰度**，得到一张“假如这里没有水”的理论背景。壁面缓慢的光照/温度梯度被保留，小范围渗水被抹除。

实现注意：

- `ksize` 必须为奇数；
- 若核边长接近图像短边，应钳位到 `min(W,H)` 以内的最大奇数，否则边界效应会把整幅图抹成常数。

### 3.3 提取局部变暗量

\[
\mathrm{Diff} = B - I
\]

| Diff 取值 | 含义 |
| --- | --- |
| \(\gg 0\) | 当前点明显冷于邻域背景 → 渗水候选 |
| \(\approx 0\) | 与背景一致 → 干燥壁面 |
| \(< 0\) | 当前点偏热（电缆、灯具、行人）→ 本方案忽略 |

只关心正值，与“找最冷点”的全局 min 策略不同：整墙均匀偏冷时 Diff 接近 0，不会误报。

### 3.4 形态学滤波与分割

1. `threshold(Diff, diff_thresh)` 得到二值图；
2. 椭圆核 **开运算（MORPH_OPEN）**：先腐蚀后膨胀，去掉传感器随机单点冷/热噪声；
3. 可选一次轻微闭运算，填补水斑内部因噪声造成的孔洞（默认关闭，以免粘连相邻独立水渍）。

### 3.5 轮廓提取与几何度量

对二值图做外轮廓提取（`RETR_EXTERNAL`）：

| 输出 | 定义 |
| --- | --- |
| Mask | 与原图同尺寸的 `CV_8UC1`，渗水像素 = 255 |
| BBox | 每个连通域的轴对齐外接矩形 |
| 面积 | `contourArea`，单位像素；若已知物距与焦距可换算 m² |
| 置信辅助量 | 区域内 `mean(Diff)`，灰阶差越大，热对比越可靠 |

过小连通域（默认面积 < 30 px）视为噪声丢弃。

## 4. 核心参数调试准则

### 4.1 高斯核尺寸 `ksize`

**规则：ksize 必须大于视野中最大预估水斑直径的 1.5 倍。**

| 常用取值 | 适用 |
| --- | --- |
| 51 × 51 | 近距离、水渍较小（点渗、滴水痕迹） |
| 71 × 71 | 默认折中 |
| 101 × 101 | 远距离或条带状湿痕较宽 |

核太小：大水斑中心被当成“背景”一起平滑，Diff 在斑块中心塌缩为 0，出现 **中空漏检**（只剩下环形边缘）。  
核太大：会把整面墙的缓慢温度场也抹平，Diff 对比下降，且计算量上升。

现场标定方法：用已知最大水渍的像素宽度 \(d\)，取奇数 \(k \approx 1.5d\) 且 \(k < \min(W,H)\)。

### 4.2 灰阶差阈值 `diff_thresh`

| 区间 | 工况 | 说明 |
| --- | --- | --- |
| 10 ~ 15 | 通风差、温差极弱（\( < 0.8^\circ\mathrm{C} \)） | 灵敏度高，噪声也会增多，必须配合开运算与最小面积 |
| 18 ~ 25 | 微风对流、温差较明显 | 抗噪优先，正常涵洞推荐起点 **20** |

`diff_thresh` 是 **相对灰阶**，不是摄氏度。未接 SDK 时不要把它当成 0.X ℃。若后续接入测温流，可把阈值改写为开尔文差，管线其余部分不变。

### 4.3 低对比度补偿 CLAHE

涵洞内外温差极小、画面灰蒙蒙时，在送入高斯差分 **之前** 对 8 位图做 CLAHE：

- `clipLimit`：2.0 ~ 4.0（过大放大噪声）
- `tileGridSize`：8×8

CLAHE 只放大局部反差，不改变“湿区相对更暗”的符号。AGC 已经把动态范围压扁时再开启；对比已经足够时保持关闭，以免把墙面纹理当渗水。

### 4.4 建议默认值

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| `ksize` | 71 | 51 ~ 101（奇数） |
| `diff_thresh` | 15 | 10 ~ 25 |
| `morph_ksize` | 3 | 3 ~ 7 |
| `min_area_px` | 30 | 视分辨率调整 |
| `enable_clahe` | false | 低对比时开启 |
| `clahe_clip` | 2.0 | 2 ~ 4 |

Demo 提供滑动条，可在实机画面上同时观察原图、背景场、Diff、Mask。

## 5. 工程接口与部署

### 5.1 模块划分

| 模块 | 路径 | 职责 |
| --- | --- | --- |
| 检测器 | `demo/include/ir_seepage_detector.hpp` | 单帧检测，无 GUI、无相机 |
| 检测器实现 | `demo/src/ir_seepage_detector.cpp` | 管线实现 |
| 现场 Demo | `demo/src/ir_seepage_demo.cpp` | V4L2 采集、叠加显示、滑动条调参 |
| 既有测温预览 | `demo/src/hongwaidemo.cpp` | 冷热点/点击测灰度，不改动 |

机器人主程序只需：

```cpp
IrSeepageDetector detector(params);
SeepageResult r = detector.detect(gray);
if (!r.regions.empty()) { /* 上报任务点 / 抓拍可见光 */ }
```

### 5.2 与巡检任务的衔接建议

- **空间**：BBox 中心映射到机器人位姿 + 云台角，写入“疑似渗水”巡检记录。
- **时间**：可选连续 \(N\) 帧（如 3 帧）同一位置命中再报警，抑制热像噪声闪烁。
- **联动**：红外检出后，切可见光近景复核（水渍反光、钟乳、钙化物）。
- **模式锁定**：相机 OSD 关闭，伪彩固定 White-Hot，避免黑热翻转导致 Diff 符号错误。

### 5.3 编译

## 6. 误检 / 漏检与对策

| 现象 | 原因 | 对策 |
| --- | --- | --- |
| 整墙误报 | 黑热模式，湿区变亮 | 强制白热；或对 Diff 取反（不推荐作为默认） |
| 螺栓、金属件误报 | 低发射率 / 反射冷天空 | 提高 `diff_thresh`；可见光联动剔除规则几何体 |
| 大面积漫湿漏检 | 水斑大于核，中心被当背景 | 增大 `ksize`；或降低云台距离、缩小 FOV |
| 边缘环形检出 | 核仍略小 | 继续加大核，或对 Mask 做一次闭运算填心 |
| 闪烁噪点 | 探测器 NETD 噪声 | 开运算 + `min_area_px` + 多帧确认 |
| 灯具/电缆热斑 | Diff 为负，本应忽略 | 确认使用 `B-I` 而非绝对值 |
| AGC 剧烈跳动 | 进出洞口 | 差分已抑制全局偏置；仍闪则做帧间中值 |

## 7. 现场标定与验收

1. **确认伪彩**：对准手心应明显变亮（白热）。反之先改相机菜单。
2. **放样**：在干燥壁面贴一块湿毛巾或喷少量水，记录像素直径，按 1.5 倍定 `ksize`。
3. **扫阈值**：从 25 往下减到水渍稳定圈出、干燥区无框为止。
4. **走航验收**：同一条涵洞往返各一次，统计：
   - 已知渗点召回；
   - 干燥段误检次数 / 百米；
   - 单帧耗时（应 ≪ 相机帧间隔）。
5. **低对比日**：雨后或内外等温时打开 CLAHE 复测，确认不会把模板缝、脚手架阴影刷成大面积 Mask。

验收通过标准建议（可按项目改）：

- 像素直径 ≥ 8、温差可辨的点渗：稳定检出；
- 干燥混凝土墙：连续 30 s 误检连通域 = 0（或仅有面积低于阈值的闪点）；
- 640×480、`ksize=71`：CPU 单帧 < 20 ms。

## 8. 适用范围与后续演进

**适用：** 白热 UVC 红外、水斑尺度小于视野约 1/3、壁面发射率较均匀的混凝土/浆砌涵洞。

**暂不作为唯一依据：**

- 黑热 / 自动伪彩切换；
- 整壁饱和潮湿（无干燥背景可估计）；
- 镜面不锈钢、积水倒影；
- 需要法定测温精度的报告（须厂家温度 SDK 或辐射标定）。

后续可平滑升级、且不推翻本管线：

1. 接入 16 位温度图后，把 `I` 换成 ℃，`diff_thresh` 改为 0.5~1.5 ℃；
2. 用引导滤波 / 滚动引导滤波替代高斯，减轻大斑中空；
3. 本检测器的 Mask 作为弱监督，再训练分割模型做精修。
